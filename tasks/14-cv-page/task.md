# Task 14. Собрать страницу `/cv`

## Цель

Собрать онлайн-резюме на основе Global `CV`.

## Структура

```txt
Header
Summary
Experience
Skills
Education
Languages
Download PDF
Contacts
```

## Header

Показывать:

```txt
name
role
location
contacts
```

## Acceptance criteria

- Данные берутся из Global `CV`.
- Если часть данных пустая, соответствующий блок скрывается.
- Download PDF работает, если PDF загружен.
- Если PDF не загружен, страница не ломается.
- Страница пригодна для отправки ссылкой.
