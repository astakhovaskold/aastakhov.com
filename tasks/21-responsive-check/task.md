# Task 21. Проверить responsive поведение

## Цель

Проверить, что сайт читается на мобильных и планшетных экранах.

## Проверить страницы

```txt
/
/projects
/projects/:slug
/posts
/posts/category/:slug
/posts/:slug
/cv
```

## Проверить

- Header.
- Hero с аватаром.
- Project list.
- Post list.
- Optional images.
- Content renderer.
- Footer contacts.

## Acceptance criteria

- Все страницы читаются на mobile.
- Hero с аватаром корректно перестраивается.
- Списки не ломаются.
- Изображения не растягивают layout.
- Навигация не переполняется.
- Горизонтального скролла нет.
