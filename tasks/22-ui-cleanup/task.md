# Task 22. Финальная чистка UI

## Цель

Убрать всё, что противоречит выбранному стилю.

## Проверить

- Нет лишних чипсов.
- Нет лишних rounded cards.
- Нет декоративных dividers.
- Нет слабого серого текста там, где нужна контрастность.
- Нет перегруженных блоков.
- Нет агентской подачи в `/projects`.
- Нет отдельной подачи кейсов как агентского портфолио.
- Нет страницы `/services`.
- Нет страницы `/cases`.
- Open Source не вынесен в отдельный публичный раздел.

## Acceptance criteria

- UI соответствует zero design.
- Визуальная система едина на всех страницах.
- Сайт выглядит как личный сайт builder-а / technical partner-а.
- Структура не расползлась обратно в агентский сайт.


## Reference mockups in this folder

- Use the archive mockups to understand rejected directions: chips, heavy cards, dividers, low-contrast gray hierarchy and decorative UI should be avoided.
