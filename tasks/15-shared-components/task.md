# Task 15. Создать общие компоненты списков

## Цель

Снизить дублирование layout-логики между главной, `/projects`, `/posts` и категориями.

## Компоненты

```txt
ProjectList
ProjectListItem
PostList
PostListItem
OpenSourceList
OpenSourceListItem
ContactLinks
SectionHeader
```

## Требования

- Компоненты должны принимать данные как props.
- Изображения должны быть опциональными.
- Пустые массивы не должны ломать страницу.
- Компоненты не должны сами добавлять тяжёлый декоративный UI.

## Acceptance criteria

- Компоненты переиспользуются на главной и индексных страницах.
- Нет дублирования layout-логики.
- Изображения опциональны.
- Компоненты не создают карточный UI без необходимости.
